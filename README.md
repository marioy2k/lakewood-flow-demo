# Lakewood Flow — browserdemo

Alleen fictieve gegevens. Geen verbinding met de serverdatabase. Wijzigingen blijven lokaal in de browser.

Voor GitHub Pages: kopieer de inhoud van deze map naar een aparte demo-repository en kies Settings → Pages → Deploy from a branch → main / (root). De echte Python-server draait niet op GitHub Pages.

De relatieve assetpaden werken ook onder een GitHub Pages projectpad.
